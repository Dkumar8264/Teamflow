# TeamFlow Build Phases

## Phase 1: Project Setup and Authentication

- Backend folder structure.
- Environment setup.
- MongoDB Atlas connection.
- User model and schema.
- Signup, login, refresh token routes.
- JWT auth middleware.
- bcrypt password hashing.
- Error handling middleware.

## Phase 2: Frontend Foundation

- React app setup with Vite.
- Routing and layout shell.
- Auth pages for signup and login.
- API client setup.
- Protected frontend routes.
- Basic dashboard placeholder.

## Phase 3: Workspace and Team Management

- Workspace CRUD.
- Invite or add members.
- Workspace roles.
- Current workspace selector.
- Member list UI.

## Phase 4: Project Management

- Project CRUD inside workspaces.
- Project members.
- Project status and metadata.
- Project list and detail pages.

## Phase 5: Task Management

- Task CRUD.
- Assignment, priority, due dates, labels, and status.
- Board, list, and detail views.
- Filtering and searching.

## Phase 6: Collaboration

- Task comments.
- Activity history.
- Notifications.
- Mentions if needed.

## Phase 7: Polish and Production Readiness

- Input validation.
- Rate limiting.
- Logging.
- Test coverage.
- Deployment configuration.
- Production environment setup.
